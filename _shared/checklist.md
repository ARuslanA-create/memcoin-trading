# Чек-лист перед отправкой на модерацию

Проходить целиком для каждой игры. Пункты, отмеченные ⚠️ — те, на которых уже
получали отказ (подробности в `moderation-lessons.md`).

## Запуск и инициализация

- [ ] `VKWebAppInit` вызывается сразу при загрузке.
- [ ] Есть индикатор загрузки (спиннер/прогресс-бар).
- [ ] Корректный запуск для нового пользователя с нуля (проверить в приватном окне).
- [ ] Полный баланс/жизни при первом входе.
- [ ] Полноценное стартовое меню, а не сразу геймплей.
- [ ] Заглушка с понятным текстом, если платформа не поддерживается.
- [ ] Работает при обрыве и восстановлении сети.

## Онбординг ⚠️

- [ ] Пошаговое обучение основной механике, а не один текстовый экран.
- [ ] Показывается только при первом запуске, состояние сохраняется.
- [ ] Есть возможность пропустить и пройти заново из меню.
- [ ] Во время онбординга не показывается реклама.
- [ ] Во время онбординга нет предложений подписки/промо/рекомендации.

## Вёрстка и адаптив ⚠️

- [ ] `env(safe-area-inset-top/bottom/left/right)` применён; нижняя часть интерфейса
      не срезается.
- [ ] Верхняя правая зона свободна — там кнопки VK (`···`, `X`, «ВКонтакте»).
      Свои элементы не перекрываются системными.
- [ ] Проверено на 320 / 375 / 414 / 768px и в горизонтальной ориентации.
- [ ] Проверено в iOS-клиенте, Android-клиенте, m.vk.ru и vk.ru.
- [ ] Светлая и тёмная темы (`VKWebAppUpdateConfig` → `scheme`).
- [ ] Комфортные отступы между кнопками, ничего не перекрывается.
- [ ] Кнопки закрытия и отказа видны и не замаскированы.
- [ ] Все тексты на русском, без опечаток и текстов-рыбы.
- [ ] Нет тестового контента и отладочных логов.

## Геймплей

- [ ] Минимум 10 минут содержательного игрового времени.
- [ ] Механика уникальна, не клон существующего мини-приложения.
- [ ] Управление интуитивное либо покрыто обучением.
- [ ] Уровень растёт только за активные действия игрока.
- [ ] Жизни/энергия восстанавливаются автоматически по таймеру.
- [ ] Прогресс сохраняется и синхронизируется между платформами.
- [ ] Звук включается и выключается мгновенно, состояние запоминается.
- [ ] Обрабатывается событие закрытия приложения (сохранение прогресса).

## Монетизация ⚠️

- [ ] Внутриигровые покупки **только за Голоса** через `VKWebAppShowOrderBox`.
- [ ] В интерфейсе магазина нет рублей, «₽», VK Pay, карт и любых денежных сумм.
- [ ] Платежи реально проходят — проверено живой покупкой, не демо-режимом.
- [ ] Покупка валидируется на сервере через Callback API / Bots Long Poll.
- [ ] Товар начисляется после подтверждения, повторное начисление невозможно.
- [ ] Отказ от платежа не блокирует основную функциональность.
- [ ] Валюту нельзя вывести, обменять на деньги или передать другому игроку.

## Реклама

- [ ] Только `VKWebAppShowNativeAds`, сторонних сетей нет.
- [ ] Баннер сверху или снизу, минимум 20px от функциональных элементов.
- [ ] Медиареклама только между экранами или вознаграждаемая.
- [ ] Не показывается при запуске и в онбординге.
- [ ] Не чаще 1 раза в 30 секунд, максимум одна за активацию.
- [ ] За просмотр не выдаётся денежная компенсация.

## Социальные механики ⚠️

- [ ] Кнопка шера реально открывает диалог (`VKWebAppShare` /
      `VKWebAppShowWallPostBox`), обрабатывает и успех, и отказ.
- [ ] Проверен шер на всех платформах, включая мобильные клиенты.
- [ ] Отказ от соцдействия не ограничивает функциональность.
- [ ] За соцдействия не выдаются дополнительные бонусы (кроме разрешённых:
      вступление в сообщество, публикация, приглашение друзей).
- [ ] Отказ пользователя запоминается, повтор не чаще раза в месяц.

## Уведомления

- [ ] Пользователь заранее проинформирован о характере уведомлений.
- [ ] Отключение доступно внутри приложения.
- [ ] Текст не длиннее 250 символов, без рекламы.
- [ ] Отказ не ограничивает функциональность.

## Документы и каталог

- [ ] Пользовательское соглашение доступно из приложения.
- [ ] Политика конфиденциальности доступна из приложения.
- [ ] Возрастное ограничение указано.
- [ ] Название и описание отражают содержание, не используют бренды VK.
- [ ] Иконка и обложки в единой стилистике, без фейковых уведомлений и рамок.
- [ ] Указан рабочий канал связи с разработчиком.

## Данные и безопасность

- [ ] Подпись параметров запуска проверяется на сервере.
- [ ] Чувствительные данные не лежат на клиенте.
- [ ] Игровое состояние, влияющее на баланс, не подделывается из консоли.
- [ ] Есть лимиты на запросы к серверу.
- [ ] Ошибки обрабатываются, пользователь видит понятное сообщение.
